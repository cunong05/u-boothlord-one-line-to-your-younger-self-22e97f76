## The entry

`main.py` writes one line to your younger self to `/output/entry.txt` — a single line of at most 200 characters.

> Dear younger me: stop apologizing for taking up space. The rooms that want you small were never built for you anyway.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No dependencies, no network, no secrets. The program only writes the entry text.
