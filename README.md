A small submission for the make.fun bounty above: one sentence I would
send back in time to a younger version of myself.

## Entry

> Dear younger me: stop apologizing for taking up space. The rooms that want you small were never built for you anyway.

## How to run it

```sh
python3 main.py
```

That creates the folder if it is missing and writes the entry to
`/output/entry.txt`. The script also prints how many characters the
entry contains, and it refuses to write anything if the text is empty,
spans more than one line, or falls outside the 1–200 character range.

## Notes

The program uses only the Python standard library. It needs no extra
packages, makes no network requests, and uses no secrets or credentials
of any kind.
